Practice: The score keeper

10 minutes. Write your code inside the script tag at the bottom of this file. (Slide 11)
THE TASK
Write a function createScoreKeeper().
It keeps a private score that starts at 0, and it returns a function.
Each time you call that returned function with some points, it adds them to the score and returns the new score.
Every score keeper keeps its own score.
EXPECTED OUTPUT (one per line)
10 15 7 35
STRETCH (finished early?)
Write createPasswordChecker(password, maxTries). It returns a function that takes a guess:
right guess → Welcome!
wrong guess → one try is used up → Wrong password. Tries left: N
no tries left → every guess, even the right one → Locked. Too many wrong tries.
EXPECTED OUTPUT
Wrong password. Tries left: 1
Welcome!
Wrong password. Tries left: 0
Locked. Too many wrong tries.
CONSOLE — press F12 (or right-click, Inspect) and open the Console tab.
Save, reload, and compare your console with the expected output.
