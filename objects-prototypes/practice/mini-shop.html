Practice: The mini shop

10 minutes. Write your code inside the script tag at the bottom of this file. (Slide 11)
THE TASK
  1. Write a constructor function Product(name, price, inStock).
  2. Give products a shared method label() on Product.prototype. It returns the name and the price, like Laptop: 650 EUR.
  3. Make an array called products with these four products:
    Laptop, 650, in stock · Headphones, 45, not in stock · Keyboard, 30, in stock · Monitor, 180, in stock
  4. Use filter, then map, to make inStockLabels: the labels of the products that are in stock.
  5. Use find to get the product named Monitor. Store it in monitor.
EXPECTED OUTPUT (one per line)
['Laptop: 650 EUR', 'Keyboard: 30 EUR', 'Monitor: 180 EUR']
Monitor: 180 EUR
true
