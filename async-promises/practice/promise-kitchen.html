Practice: The promise kitchen

10 minutes. Write your code inside the script tag at the bottom of this file. (Slide 13)
THE TASK
  1. Complete cook(item) so that it returns a promise. After 1 second: if the item is on the menu, resolve with item + ' is ready'; otherwise reject with new Error(item + ' is not on the menu').
  2. Cook pizza, then cook salad (only after the pizza is ready). Log each result when it arrives, then log All done!. Finish with one .catch that logs Kitchen problem: and the error message.
  3. Change salad to sushi and save. What prints? What does not print? Why?
EXPECTED OUTPUT FOR TASK 2 (one line per second)
pizza is ready
salad is ready
All done!
EXPECTED OUTPUT FOR TASK 3
pizza is ready
Kitchen problem: sushi is not on the menu
STRETCH (finished early?)
Add a .finally that logs Kitchen closed.
Then add a third dish to the chain.
CONSOLE — press F12 (or right-click, Inspect) and open the Console tab.
Save, let the page reload, and compare your console with the expected output.
