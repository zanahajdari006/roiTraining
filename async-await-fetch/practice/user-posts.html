Practice: Fetch a user's posts

15 minutes. Write your code inside the script tag at the bottom of this file. This page needs an internet connection. (Slide 11)
THE TASK
Complete async function getPosts(userId) so that it:
  1. Fetches that user's posts from API_URL + '/posts?userId=' + userId.
  2. Checks response.ok and throws an Error if it is false.
  3. Converts the body with response.json(). You get an array of posts.
  4. Logs how many posts there are, then each post's title.
  5. Does all of it inside try/catch. In catch, log Something went wrong: and the error message.

Then break the URL: change /posts to /postz and save. What prints now?
EXPECTED OUTPUT FOR getPosts(1)
User 1 has 10 posts
1. sunt aut facere repellat ...
2. qui est esse
... 8 more titles (they are Latin placeholder text)
EXPECTED OUTPUT AFTER BREAKING THE URL (/postz)
Something went wrong: HTTP error 404
STRETCH (finished early?)
Before the posts, fetch the user from API_URL + '/users/' + userId
and log Posts by and their name as the first line.
