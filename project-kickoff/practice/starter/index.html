Practice: Plan and set up your app

22 minutes. Open this page with Live Server. It needs an internet connection. (Slide 11)
PART A · THE PLAN · 12 MINUTES
Copy practice/project-plan-template.md into your own project folder and fill in:
  1. Your goal: one sentence.
  2. At least three user stories.
  3. Your MVP: must-haves, each with a "done when" check.
  4. Your API: open its URL in the browser and write down the fields you will use.
  5. Your wireframe on paper, and your module map: which functions go in which file.
PART B · THE SKELETON · 10 MINUTES
Copy this starter folder into your project folder. Then follow TODO 1 to 5:
  1. api.js: set API_URL and export one function for your first user story.
  2. ui.js: export one show function that logs that data.
  3. main.js: import both, and complete start().

Then break the URL in your api.js function and save. What prints now?
EXPECTED OUTPUT (Dog CEO example)
Loading...
Your dog: https://images.dog.ceo/breeds/...
EXPECTED OUTPUT AFTER BREAKING THE URL
Loading...
Something went wrong: HTTP error 404
Some APIs answer a bad request with 400 instead of 404. Either one means your error handling works.
STRETCH (finished early?)
Add a second user story: a second function in api.js, a second show function in ui.js,
and a second story function in main.js that uses them.
CONSOLE · press F12 (or right-click, Inspect) and open the Console tab.
Save, let the page reload, and compare your console with the expected output.
