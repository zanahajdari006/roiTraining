Practice: Refactor the vehicles

15 minutes. The starter code is in app.js. (Slide 10)
THE TASK
  1. In app.js, rewrite Vehicle as a class. Its constructor takes make and wheels. describe() becomes a method.
  2. Rewrite Bike as a class that extends Vehicle. Its constructor calls super(make, 2). Keep ring().
  3. Create vehicle.js with the Vehicle class and bike.js with the Bike class. Export each one.
  4. Create main.js. It imports Bike, creates new Bike('Giant'), and logs describe() and ring().
  5. In this file, change the script tag to <script type="module" src="main.js"></script> and run it with Live Server.
EXPECTED OUTPUT (one per line)
Giant has 2 wheels.
Ring ring!
CONSOLE: press F12 (or right-click, Inspect) and open the Console tab.
Save, reload, and compare your console with the expected output. The starter prints the same two lines.
